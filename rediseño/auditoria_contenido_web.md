# Auditoría de Contenido — Portfolio de Daniel Sánchez

Este documento contiene el desglose completo del contenido (textos, estructura jerárquica de páginas y mapeado de imágenes) del portfolio web. Se han omitido todas las decisiones estéticas, de diseño, colores o maquetación actual, con el fin de servir como base pura de información para solicitar un rediseño completo en un nuevo chat.
